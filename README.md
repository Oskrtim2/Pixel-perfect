# Dakingo Bakery — Pixel-Perfect Website

A pixel-perfect recreation of the **Dakingo Bakery** e-commerce experience built with **Next.js (App Router), React 19, TypeScript, and Tailwind CSS**.

## ✨ Features

- **Pixel-Perfect Hero Section**: Decadent Chocolate Bliss headline, special offer badge with copyable discount, and circular cake imagery with white borders.
- **Overlapping Category Cards**: Classic, Gourmet, Desserts, and Cookies with interactive filtering.
- **Bestsellers Catalog**: Product cards with high-resolution imagery, pricing, reviews, star ratings, and instant add-to-cart.
- **Our Promise**: 4 core guarantees, "The Magical Ticket" voucher unlocker, customer avatars, and an artisanal 6-photo bakery gallery.
- **Interactive Cart Drawer**: Real-time cart calculations, quantity adjusters, and checkout flow.
- **Customer Support & Auth**: Quick contact drawer and Login/Sign-up modals.
- **Fully Responsive**: Optimized for desktop, tablet, and mobile viewports.

## 🚀 Getting Started

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Run the development server:**
   ```bash
   npm run dev
   ```

3. **Open the browser:**
   Navigate to [http://localhost:3000](http://localhost:3000).

## 📦 Build for Production

```bash
npm run build
npm run start
```
